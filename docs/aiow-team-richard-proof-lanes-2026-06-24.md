# AIOW Team Richard Proof Lanes — 2026-06-24

Public/product-facing implementation note for AIOW.ai.

## Spunky bridge

Spunky bridge exists to route AIOW command-room context into Team Richard:

- client/project group questions;
- AIOW-made artifacts;
- missing customer proof;
- decision handoff after admin GO/NO-GO;
- project ops signals.

It is **not** a replacement for Handsome, Book or Mini. Spunky advises/contextualizes. Team Richard decides.

## Team member updates

| Member | Function | Update |
|---|---|---|
| Handsome | Commander/build owner | Final route, implementation, test, deployment, proof summary |
| Book | Strategy/UX/taste/red-team | Premium judgement, copy/claim quality, product critique |
| Mini | Outside-world/radar | X/social, SEO/GAO, market timing, opportunity cards |
| Spunky | AIOW context bridge | Client/project context, artifacts, proof requests, handoff queue |

## Homepage implementation

The homepage now shows this as a proof-lane section instead of hidden internal process. The mobile bottom nav also reflects account state:

- no account/login → plus icon;
- existing local account/access code → account/avatar state.

Dark mode bottom nav uses a dark glass pill matching the reference direction.
