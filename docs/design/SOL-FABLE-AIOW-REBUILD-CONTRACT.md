# AIOW.ai — SOL Ultra × Fable 5.1 MAX rebuild contract

Date: 2026-09-04
Status: binding implementation and release contract

## Inputs

### GPT-5.6 SOL Ultra

SOL supplied the rebuild doctrine and quality ceiling: protect the current product, retain only verified business/content/function/SEO truth, reject reskinning, develop a coherent experience rather than sections, make the product visibly work, use advanced technology only when it adds meaning, and prove WCAG 2.2 AA, responsive composition, motion fallbacks and Core Web Vitals.

### Fable 5.1 MAX

Fable supplied the AIOW-specific creative decision: **Living Blueprint**. Lead with `Hier laat u uw AI bouwen.` Use one causal copper route shared by Process, Property and Home & private life. Make Human approval the fixed authority node. Use one primary CTA, `Vraag een systeemscan aan`. Move the calculator below understanding and trust.

## Integrated decision

SOL defines how rigorously we rebuild. Fable defines what AIOW uniquely becomes.

The result is not a prettier Warm Precision page. It is an AI architecture studio expressed as one controlled story:

1. **Claim** — AIOW is where a customer has their own AI system designed, built and managed.
2. **Living demonstration** — Process, Property and Home & private life all use one inspectable route: Source → Rule → AI proposal → Human approval → Action → Management.
3. **Old complexity** — fragmented inputs, systems and responsibilities are made visible without inventing customer pain or results.
4. **New operating model** — AIOW scopes authority first, then builds and manages.
5. **Three worlds** — distinct human/environmental media, one shared build discipline.
6. **Authority and trust** — the customer remains authorised; AIOW remains responsible for management inside scope.
7. **Commercial clarity** — deterministic published indication after visitors understand what is being built.
8. **One next step** — a bounded system scan producing a decision memo.

## Signature interaction

The selected world changes the real illustrative environment and its six causal labels while preserving one stable human-approval node. Motion is finite and meaningful: media plays once, the copper route resolves, then the interface becomes calm. No looping spectacle.

## Technical decision

- Preserve Next.js 15.5.24 / React 19.2.8 for this release; no framework migration inside the visual rebuild.
- Server-render semantic content; hydrate only the world switcher, media policy and calculator.
- CSS/compositor-first motion; no Lenis, R3F, WebGL or image sequence unless a later measured requirement justifies it.
- Native scroll remains authoritative.
- Media is local, muted, audio-free, finite, non-looping and provenance-bound.
- Reduced Motion, Save Data and no-JS use posters/static causal content.
- No customer, result, testimonial, saving or capability claim without evidence.

## Release gates

- 390, 768, 1440 and 1920 exact viewport proof; 320/375/1024 remain regression widths.
- Chrome/Chromium, Safari/WebKit and Firefox behavior proof.
- Keyboard, touch, reduced motion, no-JS, Save Data and slow-network proof.
- LCP ≤2.5 s target on realistic mobile hardware/lab; INP ≤200 ms; CLS ≤0.1.
- Lighthouse ≥90 performance and ≥95 accessibility/best practices/SEO, or explicit source-level blocker before release.
- One primary CTA; no horizontal overflow; no console errors; no hidden content dependency on motion.
- Independent Product Art PASS on final exact pixels and motion.
- Exact-head Git, Vercel build and preview readback before production.
